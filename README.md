# 赶海雷达 · 烟台微信小程序

面向烟台沿海赶海用户的微信小程序 MVP，第一版包含：

- 今日赶海指数与最佳时间窗口
- 附近赶海点和地图标记
- 地点微区域推荐：东/西侧、离岸距离、目标品类
- 潮汐、天气、安全提醒卡片
- AI 查询入口（当前为本地演示适配器）
- 用户战果上报入口

## 打开方式

1. 使用微信开发者工具导入本目录。
2. 将 `project.config.json` 中的 `appid` 换成自己的小程序 AppID。
3. 当前默认使用演示数据，不需要配置 API Key 即可预览界面。
4. 上线前把天气、潮汐、地图调用放入云函数，并在小程序后台配置合法域名。

## 接入顺序

1. 创建 CloudBase 环境并部署 `cloudfunctions/ai-chat`。
2. 接入天气与潮汐数据适配器，将结果缓存到 `forecasts`。
3. 在后台录入真实赶海点、微区域、风险边界和现场校准数据。
4. 接入战果审核与预测模型，逐步替换演示数据。

## 当前状态

这是可直接预览的第一版 UI 与交互骨架。演示数据明确标注为演示预测，不能替代现场潮汐、天气和安全判断。
