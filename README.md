# 全国赶海雷达微信小程序

面向全国沿海城市的赶海辅助小程序，当前包含：

- 自动定位最近沿海城市，也可手动切换城市
- 仅对当前城市地点进行距离与安全综合排序
- 全国沿海赶海点、地图、潮汐、天气与安全评分
- 地点方位、退潮参考范围、目标海货和撤离提醒
- 跟随当前城市数据的“问赶海”AI
- 按城市展示的赶海圈与现场定位核验
- 真实定位样本参与近 14 天收获评分
- 地点位置、入口和采集规定纠错反馈
- 地点详情明确展示优先赶海岸段、到达路线和现场识别特征
- 实时接口异常时使用10分钟内最近有效海况缓存

## 打开方式

1. 使用微信开发者工具导入本目录。
2. 使用项目的正式小程序 AppID，并确认 `app.js` 中云环境 ID 正确。
3. 在小程序后台申请 `wx.getLocation`，并保持 `app.json` 中的位置用途声明。
4. 在云开发控制台启用成长计划支持的 `hy3` 文本模型。

## 云端部署

需要分别右键上传并部署：

- `cloudfunctions/forecast`：天气、海况和潮汐
- `cloudfunctions/report`：赶海圈、定位验真和真实样本汇总

需要创建以下云数据库集合：

- `field_reports`：现场收获记录
- `spot_feedback`：地点纠错反馈
- `forecast_cache`：最近一次有效海况缓存

发布时精确经纬度只参与当次距离计算，不写入数据库；数据库只保存核验结果、距离和定位精度。每次调整 `utils/data.js` 中的地点后，运行 `node scripts/sync-report-spots.js`，确保云函数白名单与前端地点同步。
